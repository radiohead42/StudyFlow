StudyFlow API

Organiza tu vida académica

StudyFlow es una API REST construida con ASP.NET Core y PostgreSQL para administrar materias y tareas universitarias.

Probar API Referencia técnica

¿Qué es StudyFlow?

StudyFlow permite organizar materias universitarias y las tareas asociadas a cada una.

Una materia puede contener múltiples tareas y cada tarea puede tener información como título, descripción y fecha límite.

Conceptos principales

Materia

Representa una asignatura académica. 

{
  "id": 1,
  "name": "Programación Web",
  "teacher": "Profesor Demo"
}

Tarea

Representa una actividad asociada a una materia. 

{
  "id": 12,
  "title": "Crear API",
  "dueDate": "2026-10-20",
  "subject": {
    "id": 1,
    "name": "Programación Web"
  }
}
