StudyFlow API

Organiza tu vida académica

StudyFlow es una API REST construida con ASP.NET Core y PostgreSQL para administrar materias, tareas y el progreso académico de cada usuario.

Probar API Referencia técnica

¿Qué es StudyFlow?

StudyFlow permite organizar materias universitarias y las tareas asociadas a cada una.

Cada usuario dispone de su propio espacio de trabajo. Las materias y tareas están asociadas al usuario autenticado, evitando que otros usuarios puedan consultar, modificar o eliminar información ajena.

Características principales

Autenticación

Registro e inicio de sesión mediante ASP.NET Core Identity y autenticación con tokens Bearer. 

POST /api/auth/register
POST /api/auth/login

Materias

Permite crear y administrar las materias pertenecientes al usuario autenticado. 

GET    /api/subjects
POST   /api/subjects
GET    /api/subjects/{id}
PUT    /api/subjects/{id}
DELETE /api/subjects/{id}

Tareas

Las tareas pertenecen a una materia y pueden incluir prioridad, estado y fecha límite. 

GET    /api/tasks
POST   /api/tasks
GET    /api/tasks/{id}
PUT    /api/tasks/{id}
DELETE /api/tasks/{id}

Dashboard

Proporciona una vista resumida del estado académico del usuario. 

GET /api/dashboard

Conceptos principales

Materia

Representa una asignatura académica perteneciente a un usuario. 

{
  "id": 1,
  "name": "Programación Web",
  "teacher": "Profesor Demo"
}

Tarea

Representa una actividad asociada a una materia. 

{
  "id": 12,
  "title": "Crear API",
  "description": "Construir el backend",
  "dueDate": "2026-10-20T18:00:00Z",
  "priority": "High",
  "status": "Pending",
  "subject": {
    "id": 1,
    "name": "Programación Web"
  }
}

Autenticación y seguridad

Bearer Token

Los endpoints protegidos requieren un access token obtenido durante el login. 

Authorization: Bearer <access_token>

Aislamiento por usuario

Cada usuario solamente puede acceder a sus propias materias y tareas. 

Usuario A
└── Materias A
    └── Tareas A

Usuario B
└── Materias B
    └── Tareas B

Rate Limiting

Los endpoints de autenticación utilizan limitación de peticiones para reducir intentos abusivos. 

/api/auth/*
→ límite de solicitudes

Consultas de tareas

El listado de tareas permite realizar búsquedas, filtros, ordenamiento y paginación.

Filtros

?status=Pending
&priority=High
&subjectId=1
&search=api

Fechas

?dueFrom=2026-10-01
&dueTo=2026-10-31

Paginación

?page=1
&pageSize=20

Ordenamiento

?sortBy=dueDate
&direction=Asc
